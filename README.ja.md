# paper-harness-undergraduate

**言語:** [简体中文](README.md) · [English](README.en.md) · [日本語](README.ja.md)

> 学部卒業論文と研究初心者向けの、レビュー優先・監査可能な研究ワークベンチです。

教員から与えられたテーマを出発点に、ローカル資料、文献マトリクス、限定的な実験、claim audit、類似度スクリーニングを段階的に扱います。高リスク段階では承認が必要であり、自動投稿、引用の捏造、AI 検出回避は行いません。

詳細は [Chinese beginner guide](docs/getting-started-zh.md) を参照してください。
